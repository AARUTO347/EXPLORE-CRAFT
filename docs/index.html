Gameplay

A factory RTS that scales with you

Mine resources, build production lines, feed ammo to your turrets, and assault enemy bases — solo, co-op, or team PvP.

Factory building

Create elaborate supply chains with production blocks, conveyors, and advanced materials. Optimize with coolant and lubricant.

Tower defense

Defend your structures from waves of enemies. Distribute liquids and fight fires, flier raids, and constant pressure.

RTS command

Produce a wide variety of units, set up assembly lines, and command armies to capture fully functional enemy bases.

Cross-platform multiplayer

Play co-op with friends or challenge them in team-based PvP across platforms, with a dedicated headless server.

Campaign & mods

Progress through a full campaign and extend the game with a rich modding API and community content.

Phase 1 · Mod & script safety

Path-traversal-safe mod names, escaped script injection, sandboxed require roots, and secure randomness.

Phase 2 · Server hardening

Safer admin/whitelist handling, ordered connection handshakes, menu nonce snapshots, bounded command socket, atomic verified updates.

Phase 3 · Untrusted input

Bounded save chunks, PNG framing validation before native decode, LZ4 packet limits, and stream/asset transfer budgets.

Get started

Build & run

Requires JDK 17. Clone the repository, then use the one-command Windows launcher or Gradle on any platform.

 Windows
REM build desktop + server JARs
run-windows.bat dist

REM run the game
run-windows.bat jar

REM run the dedicated server
run-windows.bat server-jar

REM run the test suite
run-windows.bat test
 Gradle (any platform)
# build desktop JAR
./gradlew desktop:dist

# build server JAR
./gradlew server:dist

# run tests
./gradlew tests:test

# run the game
./gradlew desktop:run

Desktop output: desktop/build/libs/ExploreCraft.jar · Server output: server/build/libs/server-release.jar
